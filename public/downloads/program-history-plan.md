# 可执行策略程序与历史反馈：首阶段开发实验

2026-10-12；依据根《实验计划.md》及 `research/RSI_SYSTEM_DESIGN_20261011.md`。用户已授权实现、运行并按完整反馈继续改进。本阶段检验共同程序接口下的历史机制，不是元程序能力确认，也不替代现行 v6 的 TrpB4 正式测试。现行 v6 源码、协议、策略和未完成结果保持原样。本阶段不读取其中途性能。

## 研究问题与共同接口

主要问题：相关条件下的修改历史，是否使固定 Qwen 改进器产生的实际部署策略优于极端收益历史、无详细历史、打乱修改—收益关联的历史和随机程序搜索？仅在 GB1 上的结论限定为同景观开发研究。

策略是 `def policy(state, tools)` 的受限 Python 程序。可赋值、计算、分支并组合共同数值工具，实际返回16个合法未测候选；不作为内层 LLM 的文字指导。允许工具为模型采集分数、排序组合、候选范围与批次选择；原始序列、已测/未测标签、候选身份不进入代码生成上下文。基础模型为 SJTU Qwen3.8-27B，固定权重、temperature=0。本阶段 R/G/P 的程序固定，仅比较预先定义的历史条件；元自修改另有后续登记。

共同限制：初始化32、8轮×16、160查询；每轮最多两种采集评分模型，共同线性CV诊断单独计时、四次排序组合，MLP每种固定五成员；每次调用只能返回一个批次。策略最多4096字符、256 AST节点；无 import、文件、网络、反射、循环和动态代码执行。候选经固定解释器执行，不在持有凭据的 broker 中执行生成代码。每个回放重置全部数值状态，既有数据库和模型权重不跨回放继承。

## 数据、对照与随机化

GB1 复用原审计候选表和历史实测标签，放入独立 workspace；复制数据不复制运行账本或已测状态。TrpB4不参与本阶段任何性能评价。正式计划中的 TrpB4仍待原v6策略冻结。

五个搜索组：`none`（无详细修改历史）、`extreme`（最低/最高收益各两条）、`context`（按父代诊断距离取相关支持与反例）、`permuted`（在本链已完成修改记录间置换收益及子代结果块，再按context检索）、`random`（共同工具与程序接口下的预定随机生成器）。前四组均最多四个历史槽、相同输入字符上限和一次模型请求/机会；none的槽明确为空，不伪造观测。输入上限相同不代表实际token相同，实际用量完整报告。

打乱组只改变模型可见的历史修改—结果关联；当前父代的合法诊断、真实筛选和最终评价不打乱。因此它检验历史关联的贡献，不证明Agent完全不依赖任何真实反馈。原始账本不修改；缺少实测结果的失败不参与置换，也不当成负收益。所有历史均来自本搜索链已经完成的回放，不借用v6或其他链。

固定菜单43方法：六种共同基础模型各自的greedy、UCB(β=.5)、EI，在global与elite_hamming_1范围分别运行，共36；MLP Thompson两个范围；随机、MLP/pairwise排序各半组合；以及ALDE DNN greedy、ALDE DNN Thompson、SSMuLA boosting greedy的已有本地协议适配。固定方法在共同10个开发起点比较，按nAUBC均值、固定菜单顺序选强基线，最终同时报告全部43方法。领域对照使用其已有CPU环境与源代码适配，不引用原论文分数。菜单覆盖全部共同基础模型的标准采集组合，避免只拿少数手选配置作为强固定对照。

新种子：工程521900–521904；固定开发522000–522009；链c开发523000+100c…+9，五块筛选+10…+59；最终GB1 524000–524049。对应组共享同链的开发/筛选起点；五链相互独立。随机搜索种子525000+c、置换526000+100c+step、筛选bootstrap527000+100c+generation。启动前审计项目全部实际配置和已登记保留种子；冲突直接停止，不静默换种子。

## 搜索、冻结和分析

每组五链，每链五代×四机会=20。初始程序为MLP UCB(β=.5)/global。所有组共用固定的有限档案探索P0：每代第一机会取当前正式部署程序，第二机会取开发均值最高且机会最早的已评价程序，后两机会取展开次数最少且机会最早的已评价程序；未通过部署筛选的分支仍保留。每个候选完整重跑同10个开发起点。历史差值相对实际父代记录；每代提名相对同一个部署程序的开发增益最大、机会最早者，与部署程序在新10个筛选起点比较。此设置避免没有接受更新时所有历史父代条件完全相同，档案规则是共同基础，不将其收益归于历史检索。接受条件沿用ΔnAUBC≥.01、配对bootstrap95%下界>0、归一化Best@160差值≥−.02。无效、语法重复、传输失败消费机会，不补提案；传输失败无策略收益。所有候选、拒绝和预测保留。

25条搜索全部结束后冻结全部部署程序、强固定方法、源、数值配置、种子与统计。使用50个共同新GB1起点，测试全部链和固定方法，不择优挑链。所有最终反馈不回流选择。候选身份及实测标签留在私有记录，公开聚合表与费用。

主指标nAUBC，Best@160与费用单列。五项预定主要比较：context−extreme、context−none、context−permuted、context−random、context−开发选定强固定方法。20,000次配对链×起点重采样，五比较Holm校正α=.05，实用门槛ΔnAUBC≥.01，终点损失下限−.02。该开发研究不能升级为原跨蛋白RSI结论。候选有效率、实际批次差异、反馈关联打乱后的提案变化是诊断，不能替代主要收益。50起点不是50蛋白；五条链不是五次元开发。

反馈顺序：完成后检查提案有效率、代码是否改变实际批次、条件历史/置换对照、独立部署收益和费用。若历史无效，先修复可行动诊断/生成机制，不默认增加元层可解决；修订进入新目录、新初始化、新登记。若条件历史有受控收益，再实现R/G/P自修改及嵌套能力评价，两轮各两候选；具体元开发任务及未用确认景观另需数据审计与登记。本阶段没有ΔQ结果。

首次实测前的接口修订：上下文距离使用六项已测诊断及六种模型的实际使用频率、排序组合次数；尺度是预先固定单位，不用全库统计、不称为学习到的校准模型。此版仅检验固定条件检索机制，不声称已经实现数学g的学习或Iφ自修改。

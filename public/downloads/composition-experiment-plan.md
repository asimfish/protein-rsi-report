# 可组合策略编辑与收益估计：GB1 机制开发实验

本实验响应用户要求补全编辑、修改收益与不确定性、实际选样行为。旧 v4 的完整负结果不改写。本轮明确使用旧结果作为先验进行方法开发：模型包含 MLP ensemble 与 epistasis regression，采集函数包括 UCB 和 expected improvement（EI）。这是新开发实验，不是独立重复，也不是 RSI 或 meta-RSI 已有优势的证明。Qwen API 准入仍未通过，本轮不调用 API，不把数值编辑器冒充 LLM。

## 实现和数学定义

策略参数为 p=(预测模型，采集函数，探索系数，候选池，批次多样性，随机槽位，排名融合，停滞条件分支)。编辑 e 对实际父代执行 p'=T_e(p)，保留其他参数；重复设置与无配置变化拒绝。编译到已有受限策略解释器，模型拟合仅用该回放已经实测的标签。单轮最多两个预测模型、16个新候选，所有回放初始化32，8轮每轮16，总预算160。

配对修改收益为 Δ_{s,e}=nAUBC(p'_e,s)−nAUBC(p_e,s)，终点约束同时报告 normalized best at 160 的配对差值。nAUBC 是32至160节点间梯形积分的归一化最优值曲线面积，沿用冻结评价器。景观归一化常数仅在可信评价器内使用。不能传给提案器或数值 worker。

条件收益预测使用岭回归：w=argmin Σ(Δ−φ(p,e,c)^T w)^2+||w||²，截距不惩罚（仅1e−8数值项），其余 ridge=1。c为已完成父代回放的6个匿名诊断均值；φ包含父代模型/采集函数/池/融合/条件分支/β、编辑类型、诊断及预定交互项。诊断尺度固定为(2,2,2,1,4,8)，截断到[−4,4]，不从全库学习。训练集按初始化整体重采样1000次，同一次抽样保留该初始化所有编辑，报告预测均值、bootstrap标准误与百分位95%区间。区间描述条件均值估计不确定性，不能当作单次发现收益的预测区间，覆盖率尚未建立；少于4个初始化或未见编辑不提供可信估计。共享父代或相同初始化不增加独立样本数。

验证阶段预测只用已完成训练父代的平均诊断；不会先读验证父代诊断来预测。预测及选择在第一次验证回放前保存。条件收益模型是否能泛化需要验证数据回答。

## 预注册矩阵与资源

只使用 GB1。TrpB4 不运行。数值参数原样使用 v4/numeric.json，包括 MLP 200 epochs，不降低训练预算以换取速度。每进程CPU2线程、GPU隐藏、不使用远程机器、wandb关闭。

|P1|P0→更换模型|mixed epistasis / UCB / 全局池|

## 实际选样验证

1. 同种子初始化32的标签与顺序必须完全相同，第一批父/子策略候选交集、变化数量和Jaccard才可归因于编辑。
2. 后续闭环8批报告平均Jaccard，但不同策略已测历史可能不同，不能称为同状态干预。
3. P3逐轮影子执行P2，P7逐轮影子执行P0：在子代的同一已测状态、同一个拟合种子、同一复制随机数状态下执行父代选择。独立工具缓存，影子批次不查询任何标签，不回传给主动策略。报告真实候选差异、模型调用与停滞触发；没有反事实fitness收益。
4. 合成环境证明加入影子执行不改变主动批次，并通过真实bwrap/stdio/SQLite预算审计。合成结果不当作生物性能。

## 完整性与下一步

研究运行需独立代码评审和另一fresh Agent逐字ENV复验通过，记录same-family、provisional、scientific_support=false。新代码/计划/ENV冻结并写注册文件后才第一次查询。原v4的120源和正在运行v6的119源只核对身份，不读v6中途策略或分数。种子只审计配置/注册元数据；冲突直接停止，不替换种子。每次回放先写allocation，正常及异常（包括result之前异常和审计失败）均从自己的只读SQLite收费事件结算；无法读取时保留未知收费记录，不当零。进度明确区分已结算查询与尚未结算回放。任何回放失败保留收费记录并停止，不补跑、不隐式重启。

这里补全的是RSI所需的数值组件与可检验接口。只有完成上述真实结果分析后，才能制定下一轮等预算的多代历史引导搜索、无历史/随机历史与固定策略比较；跨任务泛化与提案/检索/接受规则的递归自修改尚未验证。公开报告同时保留旧负结果。
